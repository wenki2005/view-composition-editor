三步开始使用

01 / 下载

下载并解压

点击上方下载按钮，获取最新项目 ZIP 并解压到任意目录。

02 / 安装

启动编辑器

双击 启动编辑器.cmd，首次启动会自动安装依赖。

03 / 编辑

选择你的项目

在编辑器中打开包含 HTML 页面的项目文件夹，开始调整和保存。
