# Visual direction

The editor is an operate surface. It uses a quiet ink-blue workspace, warm amber selection states, and cool paper panels so the page being edited remains the visual focus.

- Canvas: deep navy with a fine drafting grid.
- Panels: slightly lighter blue-black surfaces with thin cool borders.
- Accent: amber for selection, active handles, and save confirmation.
- Text: compact system sans with high-contrast headings and muted supporting labels.
- Layout: top command rail, narrow project rail, wide preview canvas, narrow inspector.
- Motion: short state transitions only; no page-load choreography.
